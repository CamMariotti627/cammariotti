Linear vs. Nonlinear Solver Comparison

The classic "guns and butter" resource-allocation problem, solved first as a linear program, then re-solved with a nonlinear volume bonus.

Solution Comparison

ModelGunsButter (tons)Storage Used / LimitBudget Used / LimitRevenue
Linear (Simplex)41220.0 / 21$1,800 / $1,800$2,580
Nonlinear (Evolutionary)6916.5 / 21$1,800 / $1,800$3,020

Both models share the same budget ($1,800) and storage constraint (21 units), unit prices ($150 guns / $100 butter), and per-unit revenue ($195 / $150). The nonlinear model adds a volume bonus for selling 5+ guns, breaking linearity — the Simplex method solves the linear case exactly by checking only polytope corner points, while the nonlinear case requires an evolutionary solver to search for the global optimum, with results constrained to integer units since fractional guns or butter tons aren't sellable.
