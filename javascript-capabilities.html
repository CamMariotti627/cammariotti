Multiple loop strategies, same result

function factorialWhile(n) {
  var total = 1, i = 1;
  while (i <= n) { total *= i; i++; }
  return total;
}

Same algorithm implemented with for, while, and do-while loops to show command of each control structure.

function everyOtherElement(arr) {
  var result = [];
  for (var i = 0; i < arr.length; i++) {

}

DOM manipulation & live unit conversion

function fahrenheitToCelsius() {

}
