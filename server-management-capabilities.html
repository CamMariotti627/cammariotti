Representative Ruleset

# Default posture: deny everything, then allow explicitly block in log all block out log all # Exempt loopback so local services can still reach each other set skip on lo0 # "quick" stops rule evaluation at the first match — # without it, traffic falls through to the default block above pass out quick on em0 proto tcp from any to any keep state pass in quick on em0 proto tcp to port { 22, 80 } keep state pass in quick on em0 proto icmp icmp-type echoreq keep state

Illustrative ruleset reconstructed from the module's documented debugging process — not the literal submitted file.

The fix was two-fold: adding quick so the first matching rule short-circuits evaluation instead of silently falling through to the default block, and exempting the loopback interface (lo0) so local services kept working once the default-deny policy took effect. Also configured FreeBSD jails for isolated service environments as part of the same module.
